# Дневник сна — Android MVP 1.1

Небольшое Android-приложение с тёмным интерфейсом: календарь сна, запуск отслеживания вручную, автоматическое окончание по событию разблокировки с двухчасовым защитным окном, анкета после каждой ночи, персональная статистика и экспорт Excel.

## Что есть в приложении

- **Календарь:** продолжительность ночи показывается на дате, с которой началось фактическое отслеживание сна.
- **Кнопка «Я ложусь спать»:** запускает запись и постоянное системное уведомление.
- **Защитное окно 2 часа:** если телефон разблокировали раньше, чем через 2 часа после текущего начала, время начала сбрасывается на точный момент этой разблокировки. Каждая новая разблокировка в пределах очередных 2 часов снова переносит начало. Первая разблокировка спустя 2 часа или позже завершает запись.
- **Ручная остановка:** в приложении и уведомлении можно завершить запись вручную, в том числе до истечения двух часов.
- **Анкета непосредственно в приложении:** выбери завершённую ночь в календаре и нажми «Заполнить вопросы о ночи». Вопросы: самочувствие после пробуждения, выспался ли, энергия утром, стресс перед сном, количество пробуждений, поздний кофеин, дневной сон и заметки. Ответы сохраняются на выбранную дату, их можно изменить позднее.
- **Советы:** подсказка по длительности сна и отметке «выспался».
- **Аналитика:** средняя продолжительность, доля ночей с ощущением выспанности, персональный ориентир по удачным ночам, средние часы отбоя и подъёма.
- **Excel:** экспорт настоящего `.xlsx` с листами «Дневник» и «Анализ».
- **Локальное хранение:** SQLite и SharedPreferences на устройстве, без сетевых запросов.

## Как работает двухчасовое окно

Пример: нажал «Я ложусь спать» в 23:00.

1. Разблокировал телефон в 23:40 — начало переносится на 23:40.
2. Снова разблокировал в 00:50 (прошло 1 ч 10 мин) — начало переносится на 00:50.
3. Разблокировал в 07:30 (прошло 6 ч 40 мин) — запись завершается. В дневник попадёт период с 00:50 до 07:30.

Если разблокировать ровно через 2 часа или позже — запись завершится. Если разблокировать раньше — отсчёт начинается заново с момента разблокировки. Если повторная разблокировка переходит через полночь, ночь переносится на новую календарную дату.

## Сборка APK

1. Установи Android Studio с JDK 17+ и Android SDK Platform 37.
2. Открой папку `SleepJournal` как проект Gradle.
3. В архиве есть `gradle-wrapper.properties`, но нет исполняемых файлов Wrapper (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`). Поэтому, если Android Studio не сможет сама инициализировать Gradle, установи Gradle 9.5.0 и выполни в корне проекта `gradle wrapper --gradle-version 9.5.0`, затем повтори Gradle Sync.
4. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Android Studio создаст debug APK в `app/build/outputs/apk/debug/`.
6. Установи APK на устройство Android 8.0 или новее и разреши уведомления.

**Альтернатива без Android Studio:** в проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`. Если загрузить папку проекта в GitHub-репозиторий, workflow запустится при push в `main` или вручную через вкладку **Actions → Build Android APK → Run workflow**. После успешной сборки APK можно забрать из артефакта `sleepjournal-debug-apk` внизу страницы запуска. Workflow сначала запускает тесты двухчасового правила, затем собирает debug APK.

Проект настроен на Android Gradle Plugin 9.3.0, Gradle 9.5.0 и Kotlin/Compose compiler plugin 2.4.21. Согласованность этих версий сверена с таблицей совместимости Kotlin и официальными release notes AGP 9.3. См.:
- https://developer.android.com/build/releases/agp-9-3-0-release-notes
- https://kotlinlang.org/docs/gradle-configure-project.html

В текущей среде APK не удалось собрать: здесь нет Android SDK (`android.jar`, `aapt2`, Build Tools) и Gradle, а подключение к серверам загрузки Gradle недоступно. В архив включён обновлённый исходный проект, но не поддельный или пустой APK. После сборки Android Studio установочный файл можно будет отправить на телефон.

## Проверка поведения

1. Запусти «Дневник сна» и нажми «Я ложусь спать».
2. Разблокируй телефон, например, через 30 минут: время начала должно обновиться.
3. Снова разблокируй в пределах двух часов: начало должно обновиться ещё раз.
4. Разблокируй после того, как от последнего начала прошло не менее двух часов: запись должна завершиться.
5. Открой завершённую ночь в календаре и нажми «Заполнить вопросы о ночи».
6. Перейди на вкладку «Анализ» и проверь, что ответы учитываются. В «Настройках» экспортируй Excel.

## Ограничения Android

- Android не предоставляет приложению отдельного события «введён пароль». Используется `ACTION_USER_PRESENT`: система сообщает, что экран блокировки снят. Это может быть PIN-код, пароль, отпечаток, лицо или свайп при незащищённой блокировке.
- Постоянное отслеживание работает через foreground service специального типа `specialUse` с уведомлением. Для публикации в Google Play потребуется обосновать этот тип сервиса и пройти проверку.
- Некоторые прошивки могут агрессивно останавливать фоновые службы. Может потребоваться отключить оптимизацию батареи для приложения.
- В этой версии хранится одна запись на календарную дату начала; несколько отдельных сессий за одну дату не суммируются.
- Персональный ориентир рассчитывается по ответам пользователя и не является медицинской рекомендацией.

## Структура проекта

- `MainActivity.kt` — тёмный интерфейс, календарь, анкета, аналитика и экспорт.
- `SleepTrackerService.kt` — foreground service, события разблокировки и двухчасовое окно.
- `SleepTrackingPolicy.kt` — чистая функция принятия решения для события разблокировки.
- `SleepDatabase.kt` — локальная SQLite база и сохранение активной ночи.
- `SleepEntry.kt` — модель дневника.
- `XlsxExporter.kt` — генератор Excel.
